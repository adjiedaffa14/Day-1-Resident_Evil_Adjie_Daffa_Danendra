## 4. Dokumentasi Kegiatan Workshop

### A. Rangkuman Materi Workshop
Materi workshop Day 1 dibawakan oleh **Nugi Farhan** (Senior Product Designer) dengan topik utama *"Building with AI, Managing Change with GitHub"*. Sesi ini mencakup dua bagian utama:

1. **Prompt Engineering (Building with AI):**
   * Mempelajari cara merancang instruksi (prompt) agar AI memberikan jawaban yang akurat, relevan, dan berkualitas.
   * Memahami struktur prompt yang baik, yang terdiri dari 4 elemen utama: **Role** (Peran), **Task** (Tugas), **Context** (Konteks), dan **Format** (Format Output).
   * Mengetahui keuntungan prompt engineering, seperti meningkatkan performa AI, mengurangi respons ofensif/bias, meningkatkan kontrol, serta memberikan hasil yang sesuai ekspektasi.
   * Implementasi pembuatan aplikasi sederhana *Student Task Planner* memanfaatkan asistensi AI.

2. **Git & GitHub (Managing Change with GitHub):**
   * **Perbedaan Git & GitHub:** Git adalah Version Control System (VCS) lokal terdistribusi untuk melacak perubahan kode, sedangkan GitHub adalah platform cloud berbasis web untuk menyimpan repository Git secara online dan melakukan kolaborasi.
   * **Git Workflow:** Memahami 3 area kerja utama pada Git, yaitu *Working Directory*, *Staging Area* (Index), dan *.git directory* (Repository).
   * **Perintah Dasar Git & GitHub:** 
     - Perintah dasar lokal: `git init`, `git add .`, dan `git commit -m "pesan"`.
     - Perintah penghubung remote: `git remote add`, `git push origin main`, dan `git pull origin main`.
   * **Setup & Autentikasi:** Konfigurasi identitas Git (`user.name` & `user.email`), verifikasi integrasi VS Code, serta pembuatan dan pendaftaran *SSH Key* (`Ed25519`) ke akun GitHub untuk koneksi yang aman.

### B. Poin-Poin Penting & Pengetahuan Baru
* **Pentingnya Konteks dalam Prompt AI:** Memberikan instruksi spesifik dengan struktur *Role, Task, Context, Format* menghasilkan respons kode yang jauh lebih matang dibandingkan prompt singkat tanpa konteks.
* **Manajemen Perubahan Kode (Version Control):** Pentingnya melakukan commit secara berkala untuk mencatat riwayat perubahan kode sehingga memudahkan pelacakan bug dan pengembalian versi kode (*rollback*) jika terjadi masalah.
* **Alur Kerja Terintegrasi:** Mengetahui cara menggabungkan efisiensi *generative AI* untuk membuat struktur dasar aplikasi web dan mengelolanya secara terstruktur menggunakan Git & GitHub.
* **Keamanan Konfigurasi Git:** Memahami pentingnya menyiapkan autentikasi SSH Key (`ssh-keygen -t ed25519`) agar koneksi terminal lokal ke repository GitHub remote aman tanpa perlu memasukkan kredensial berulang kali.
